# Тестирование API сервиса аренды самокатов

## Описание проекта
Автотесты для проверки API сценариев сервиса аренды самокатов.

## Установка и запуск
1. Клонировать репозиторий
2. Установить зависимости: `pip install -r requirements.txt`
3. Запустить тесты: `pytest create_order_test.py -v`

## Структура проекта
- `configuration.py` - URL и пути к API эндпоинтам
- `data.py` - тестовые данные
- `sender_stand_request.py` - функции для отправки запросов
- `create_order_test.py` - файл с автотестами

## Тестируемые сценарии
1. Создание заказа
2. Получение заказа по треку
3. Проверка кода ответа 200 при успешном получении заказа

## Логи
Логи приложения находятся в файле `/var/www/backend/logs/error.log`
